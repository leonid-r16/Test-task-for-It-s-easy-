# Измеритель скорости загрузки

Небольшой CLI-скрипт на Python для измерения времени загрузки файла и средней скорости передачи данных с указанного URL.

> Результат характеризует загрузку с конкретного сервера и зависит от его нагрузки, сетевого маршрута и размера файла. Это не универсальный тест скорости интернет-подключения.

## Возможности

- Выполняет запросы к указанному URL последовательно.
- По умолчанию делает 10 замеров.
- Измеряет время загрузки каждого успешного ответа и объём полученных данных.
- Вычисляет среднее время загрузки, общий объём скачанных данных и среднюю скорость загрузки.
- Повторяет запрос при тайм-ауте, сетевой ошибке и HTTP-статусах `429`, `500`, `502`, `503`, `504`. По умолчанию выполняется до 3 попыток с увеличивающейся задержкой между ними.
- Проверяет параметры командной строки.
- Использует Ruff для проверки и форматирования кода.

## Требования

- Python 3.12
- Зависимости из `requirements.txt`.

## Установка

Клонируйте репозиторий и перейдите в его каталог:

```bash
git clone <URL-репозитория>
cd <каталог-репозитория>
```

Создайте и активируйте виртуальное окружение.

**Linux / macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

**Windows PowerShell:**

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

## Использование

Базовый запуск:

```bash
python main.py "https://example.com/path/to/file.jpg"
```

С дополнительными параметрами:

```bash
python main.py "https://example.com/path/to/file.jpg" --requests 5 --timeout 15
```

Справка по параметрам:

```bash
python main.py --help
```

### Аргументы

| Аргумент | Обязательный | Значение по умолчанию | Описание |
|---|---|---|---|
| `url` | Да | — | URL файла для загрузки |
| `--requests` | Нет | `10` | Количество замеров; должно быть больше нуля |
| `--timeout` | Нет | `10.0` | Тайм-аут одного запроса в секундах; должен быть больше нуля |

## Как рассчитываются показатели

- **Среднее время загрузки** — суммарное время успешных замеров, делённое на количество успешных замеров.
- **Объём скачанных данных** — суммарный размер тел успешных HTTP-ответов.
- **Средняя скорость загрузки** — общий объём успешно скачанных данных, делённый на суммарное время успешных замеров.

Для перевода байтов в мегабайты используется десятичное значение: `1 МБ = 1 000 000 байт`. Паузы между запросами и задержки перед повторными попытками не входят во время успешного замера. Неудачные попытки также не включаются в суммарное время и объём скачанных данных.

Если все запросы завершились неудачно или доля неудачных замеров превышает 20%, скрипт сообщает, что измерение недостоверно, и не выводит итоговые показатели.

## Проверка и форматирование кода

Проверить код с помощью Ruff:

```bash
ruff check .
```

Автоматически отформатировать код:

```bash
ruff format .
```

Проверить форматирование без изменения файлов:

```bash
ruff format --check .
```

Настройки Ruff находятся в `pyproject.toml`.
